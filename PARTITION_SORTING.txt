╔══════════════════════════════════════════════════════════════════════════════╗
║                          核心排序原则                                           ║
╚══════════════════════════════════════════════════════════════════════════════╝

排序规则：按时间戳倒序排列（最新在前，最旧在后）

数据结构：单向链表（Singly Linked List）

指针方向：
  - head → 指向最新的分区
  - tail → 指向最旧的分区
  - next → 指向下一个较旧的分区

╔══════════════════════════════════════════════════════════════════════════════╗
║                          内存分区 vs 磁盘分区                                     ║
╚══════════════════════════════════════════════════════════════════════════════╝

┌─────────────────────────────────────────────────────────────────────────────┐
│                         Memory Partition（内存分区）                           │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  位置：列表头部（1-2个）                                                       │
│  状态：可写（ACTIVE）                                                          │
│  特性：                                                                      │
│  ├── 数据存储在堆中（slice）                                                  │
│  ├── 有序切片，CPU 缓存友好                                                   │
│  ├── 支持实时写入                                                            │
│  ├── 支持乱序数据缓冲                                                        │
│  └── 高速读取（最新数据通常在内存中）                                         │
│                                                                             │
│  数据结构：                                                                  │
│  ├── metrics (sync.Map)  ──→ 指标集合                                        │
│  ├── points []DataPoint  ──→ 数据点切片                                      │
│  └── outOfOrderPoints   ──→ 乱序数据缓冲                                     │
│                                                                             │
│  生命周期：                                                                  │
│  创建 → 接收数据 → 填满 → 持久化 → 变为 Disk Partition                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                         Disk Partition（磁盘分区）                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  位置：列表中部和尾部                                                         │
│  状态：只读（READ_ONLY）                                                      │
│  特性：                                                                      │
│  ├── 数据持久化到磁盘                                                        │
│  ├── 使用 mmap 内存映射                                                      │
│  ├── 数据压缩（Gorilla 算法）                                                │
│  ├── 按需读取，不全部加载                                                    │
│  ├── 操作系统管理缓存                                                        │
│  └── 支持过期自动删除                                                        │
│                                                                             │
│  文件结构：                                                                  │
│  ├── p-{minTimestamp}-{maxTimestamp}/                                        │
│  │   ├── data          ──→ 压缩的数据文件（mmap）                             │
│  │   └── meta.json     ──→ 分区元数据                                        │
│  │       ├── MinTimestamp                                                      │
│  │       ├── MaxTimestamp                                                      │
│  │       ├── NumDataPoints                                                     │
│  │       └── Metrics        ──→ 指标索引（名称、偏移量、时间范围）             │
│                                                                             │
│  查询流程：                                                                  │
│  1. 读取 meta.json 获取指标偏移量                                             │
│  2. seek 到 data 文件的指定位置                                              │
│  3. 解码数据点                                                               │
│  4. 过滤时间范围                                                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘


╔══════════════════════════════════════════════════════════════════════════════╗
║                          插入新分区的流程                                      ║
╚══════════════════════════════════════════════════════════════════════════════╝

初始状态：
head → [Memory Part 1] → [Memory Part 2] → [Disk Part 1] → nil

插入新分区：
1. 创建新的内存分区
2. 插入到链表头部

插入后：
head → [Memory Part NEW] → [Memory Part 1] → [Memory Part 2] → [Disk Part 1] → nil
        ↑
      新分区

时间线：
旧 ──→ [Disk Part 1] → [Memory Part 2] → [Memory Part 1] → [Memory Part NEW] ──→ 新


╔══════════════════════════════════════════════════════════════════════════════╗
║                          持久化分区到磁盘                                      ║
╚══════════════════════════════════════════════════════════════════════════════╝

持久化前：
head → [Memory Part 1] → [Memory Part 2] → [Disk Part 1] → [Disk Part 2] → nil
       (第3个分区，需要持久化)

持久化步骤：
1. 压缩数据 → data 文件
2. 创建元数据 → meta.json
3. 创建磁盘分区对象
4. 替换链表中的节点

持久化后：
head → [Memory Part 1] → [Memory Part 2] → [Disk Part 1*] → [Disk Part 2] → nil
                                             ↑
                                   新的磁盘分区（替换原内存分区）

磁盘文件创建：
./data/
├── p-1600000001-1600003600/
│   ├── data          ← 压缩的数据
│   └── meta.json     ← 元数据


╔══════════════════════════════════════════════════════════════════════════════╗
║                          删除过期分区                                          ║
╚══════════════════════════════════════════════════════════════════════════════╝

检查条件：
partition.expired()  ←  基于配置的 retention 时间

过期前：
head → [Memory Part 1] → [Memory Part 2] → [Disk Part 1] → [Disk Part 2*] → [Disk Part 3*] → nil
                                                                        ↑
                                                                  过期分区（删除）

删除后：
head → [Memory Part 1] → [Memory Part 2] → [Disk Part 1] → [Disk Part 2] → nil
                                                                        ↑
                                                              新的尾部

磁盘文件删除：
./data/
├── p-1599992801-1599996400/  ← 删除此目录
│   ├── data
│   └── meta.json


╔══════════════════════════════════════════════════════════════════════════════╗
║                          为什么这样排序？                                        ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. 查询优化
   ├─ 时序数据通常查询最新数据
   ├─ 最新分区在头部，快速访问
   └─ 内存分区提供高速读取

2. 写入优化
   ├─ 新分区总是插入到头部（O(1)）
   ├─ 头部分区总是可写的
   └─ 不需要遍历整个列表

3. 内存管理
   ├─ 只保留少量内存分区（1-2个）
   ├─ 历史数据持久化到磁盘
   └─ 减少内存占用

4. 乱序数据处理
   ├─ 保留2个可写分区
   ├─ 接受时间戳较早的数据
   ├─ 临时缓冲乱序数据
   └─ 刷新时合并

5. 缓存友好
   ├─ 内存分区使用有序切片
   ├─ CPU 缓存命中率高
   └─ 磁盘分区使用 mmap，操作系统管理缓存


╔══════════════════════════════════════════════════════════════════════════════╗
║                          迭代顺序（从新到旧）                                   ║
╚══════════════════════════════════════════════════════════════════════════════╝

查询时的迭代顺序：

iterator := partitionList.newIterator()

第1次 next() → Memory Part 1  ← 最新分区
第2次 next() → Memory Part 2  ← 次新分区
第3次 next() → Disk Part 1    ← 第3个分区
第4次 next() → Disk Part 2    ← 第4个分区
第5次 next() → Disk Part 3    ← 第5个分区
...
第N次 next() → Disk Part N    ← 最旧分区
第N+1次 next() → nil          ← 迭代结束

为什么这样迭代？
├─ 大多数查询关注最新数据
├─ 可以提前终止（如果找到所有数据）
├─ 减少不必要的磁盘访问
└─ 利用缓存（内存分区）


╔══════════════════════════════════════════════════════════════════════════════╗
║                          代码示例                                              ║
╚══════════════════════════════════════════════════════════════════════════════╝

插入分区（头部插入）：

func (p *partitionListImpl) insert(partition partition) {
    node := &partitionNode{val: partition}
    
    if head != nil {
        node.next = head  // 新节点指向旧头节点
    }
    
    p.setHead(node)  // 更新头指针为新节点
}

图示：
插入前：head → [A] → [B] → [C]
插入后：head → [NEW] → [A] → [B] → [C]
         ↑
      新头节点


迭代器遍历（从新到旧）：

iterator := partitionList.newIterator()
for iterator.next() {
    partition := iterator.value()
    // 处理分区（从最新到最旧）
}

图示：
iterator.current = [A]  ← 第1次
iterator.current = [B]  ← 第2次
iterator.current = [C]  ← 第3次
iterator.current = nil  ← 结束


╔══════════════════════════════════════════════════════════════════════════════╗
║                          总结                                                   ║
╚══════════════════════════════════════════════════════════════════════════════╝

排序方式：时间戳倒序（新 → 旧）

数据结构：单向链表

分区类型：
├─ Memory Partition（内存分区）
│  └─ 位置：头部（1-2个），可写
└─ Disk Partition（磁盘分区）
   └─ 位置：中部和尾部，只读

关键操作：
├─ insert()   → O(1)，头部插入
├─ remove()   → O(n)，查找删除
├─ swap()     → O(n)，查找替换
└─ iterate()  → O(n)，从新到旧

设计优势：
✓ 快速访问最新数据
✓ 高效插入新分区
✓ 内存占用可控
✓ 支持乱序数据
✓ 缓存友好
